Faculty Academic Tracker & Defaulter Management System

A Python-based web application designed to help faculty manage academic submissions, attendance, internal marks, and student performance.

Features

- Faculty dashboard
- Student record management
- Assignment and practical submission tracking
- Attendance shortage reports
- Internal marks management
- Interactive academic charts
- CSV report export
- SQLite database storage

Technologies

- Python
- Streamlit
- Pandas
- Plotly
- SQLite and SQL

Run locally

1. Install Python.
2. Install dependencies using "pip install -r requirements.txt".
3. Run "python -m streamlit run app.py".

This project is developed as a Python for Data Science Problem Based Learning (PBL) project.
